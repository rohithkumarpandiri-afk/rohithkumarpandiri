# Rohith Pandiri — Portfolio

A responsive personal portfolio built from Rohith Pandiri's resume.

## Files
- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — small interactions
- `assets/Rohith-Pandiri-Resume.pdf` — downloadable resume

## GitHub Pages
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload all files while keeping the `assets` folder.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.
